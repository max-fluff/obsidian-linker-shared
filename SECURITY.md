# Security policy

## Reporting a vulnerability

Please report security issues in these shared modules — they ship inside all four Linker plugins **privately**, not in a public issue:

**[Report a vulnerability](https://github.com/max-fluff/obsidian-linker-shared/security/advisories/new)**
(GitHub → Security → Report a vulnerability)

Include what an attacker controls (a note, a vault, a file on disk), what they get, and the
steps or a sample note that shows it. You'll get a reply within a week; once a fix is
released the advisory is published with credit to you, unless you'd rather stay anonymous.

## Supported versions

Supported: the commit the latest release of each plugin vendors.
